# Synthetic example experiments

Generated by `scripts/make_examples.py` from `xpkit.sim` (seed 2024). Not real data.

* `checkout_test.csv`: 20,000 users, 50/50 randomized. **True effects:** revenue +0.600, conversion +0.0080.
* `checkout_test_srm.csv`: same design, but 25% of low-engagement treated users were never logged (selective SRM, 18,777 rows remain). The naive estimate is biased upward; the report flags the SRM and refuses to interpret it.

**Caveat:** a subtler loss can slip past the SRM check. In `results/validation/stage2.json` (E_srm), a 5% selective loss at n=20k was flagged in only 59% of simulations. Passing the SRM check is necessary, not sufficient.

Run `xpkit-report examples/checkout_test.csv examples/checkout_test.yaml -o reports/checkout_test.html`.
