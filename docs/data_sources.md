## Sampling and reproducibility

- **Criteo:** each row is kept independently with probability 1,000,000 / 13,979,592, using `numpy.random.default_rng(20240601)` in file order. The result has 1,001,957 rows. It is a simple random sample, so treatment/control proportions are preserved in expectation (the observed treated share is checked with an SRM test against 85%).
- **GA360:** one query (`xpkit.datasets.GA360_QUERY`) pulls session-start attributes and outcomes only. Session totals reproduce the original analysis exactly (664,479 desktop / 208,725 mobile sessions; 10,528 / 856 conversions).

## Blocked or unavailable steps

- GA360 needs a BigQuery billing project and credentials (`GCP_PROJECT`, `gcloud auth application-default login`). Without them, `case_studies/03_ga360.py` exits with code 2 and prints `BLOCKED`. The committed results in `results/case_studies/ga360.json` came from an authenticated run on 2026-11-06.
- DiD: no suitable public panel with a genuine intervention was identified, so DiD is shown on simulated data only.
